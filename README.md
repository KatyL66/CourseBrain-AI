# CourseBrain

Private beta of Brightspace course assistant. Download it, load it in Chrome, and enter an invite code.

## Download

[coursebrain-extension-beta.zip](https://github.com/KatyL66/CourseBrain-AI/raw/main/coursebrain-extension-beta.zip)

## Install

Chrome cannot install a ZIP directly.

1. Download the ZIP above and unzip it.
2. Open the unzipped folder and confirm that `manifest.json` is in that folder. If the folder contains another folder, open that inner folder until you see `manifest.json`.
3. Open Chrome and go to `chrome://extensions`.
4. Turn on **Developer mode** in the top-right corner.
5. Click **Load unpacked** and select the folder that contains `manifest.json`.

## Use

1. Sign in to [Brightspace](https://brightspace.usc.edu) and open a course.
2. Click the puzzle icon to the right of the address bar, then click CourseBrain. The side panel opens. You can pin it to the toolbar if you want.
3. The first time, choose **English** or **中文**. You can switch later with **EN / 中文** at the top of the side panel. Then enter your invite code and click **Save invite code**. The code stays in this browser. Ask the CourseBrain maintainer for a code.
4. On the course page, click **Sync this Brightspace course**.
5. After sync finishes, ask a question. Click a source in the answer to open that material.

## Notes

- Use it only on `https://brightspace.usc.edu`.
- Do not enter an OpenAI key. One is not required.
- Each invite code has a daily limit on questions and syncs.

Brightspace 课程助手的 Private Beta 安装包。下载后在 Chrome 里加载，输入邀请码即可使用。

## 下载

[coursebrain-extension-beta.zip](https://github.com/KatyL66/CourseBrain-AI/raw/main/coursebrain-extension-beta.zip)

## 安装

Chrome 不能直接安装 ZIP。

1. 下载上面的 ZIP 并解压。
2. 打开解压出来的文件夹，确认根目录里能直接看到 `manifest.json`。如果里面又套了一层文件夹，进入那一层，直到看到 `manifest.json`。
3. 打开 Chrome，在地址栏输入 `chrome://extensions`。
4. 打开右上角的「开发者模式」。
5. 点击「加载已解压的扩展程序」，选择含有 `manifest.json` 的那个文件夹。

## 使用

1. 登录 [Brightspace](https://brightspace.usc.edu)，打开一门课。
2. 点击地址栏右侧的拼图图标，再点击 CourseBrain。侧边栏会打开。需要的话可以把它固定在工具栏上。
3. 第一次使用时先选择 English 或中文。之后可以在侧边栏顶部用 EN / 中文 切换。然后输入邀请码，点击「保存邀请码」。邀请码只保存在这台浏览器里。请向 CourseBrain 的维护者索取邀请码。
4. 在课程页面点击「同步当前 Brightspace 课程」。
5. 同步完成后直接提问。点击答案里的出处，会打开对应材料。

## 说明

- 只在 `https://brightspace.usc.edu` 上使用。
- 不需要、也不要填写 OpenAI Key。
- 每个邀请码每天的提问次数和同步次数有上限。
